# 03: 비밀번호로 방명록 글 삭제

**What to build:** 글쓴이가 방명록 글의 "삭제"를 누르면 그 자리에 비밀번호 입력칸이 펼쳐지고, 올바른 비밀번호를 입력하면 방명록 글이 목록에서 사라진다. 비밀번호가 틀리면 삭제가 거부되고 해당 방명록 글 아래에 안내가 뜬다. 이미 삭제된 방명록 글이면 따로 안내하고 목록을 새로 고친다. 이 티켓에서 "한 번에 하나의 인라인 입력칸만 열림" 구조를 처음 만들며, 04가 이를 재사용한다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 02 (방명록 글 작성)

**Status:** ready-for-agent

- [ ] guestbook 모듈의 삭제 연산이 `ok` | `wrong-password` | `not-found`를 반환한다
- [ ] 비밀번호 비교는 앞뒤 공백을 자른 값으로 `timingSafeEqual`을 사용한다
- [ ] 각 방명록 글에 "삭제" 버튼이 있고, 누르면 그 자리에 비밀번호 입력칸이 펼쳐진다 (한 번에 하나만 열림, 취소 가능)
- [ ] 올바른 비밀번호 → 방명록 글이 목록에서 사라지고 입력칸이 닫힌다
- [ ] 틀린 비밀번호 → 해당 방명록 글 아래에 빨간 "비밀번호가 일치하지 않습니다", 방명록 글은 남아 있다
- [ ] 이미 삭제된 방명록 글 → "이미 삭제된 글입니다" 안내 후 목록이 새로 고쳐진다
- [ ] 테스트: 올바른/틀린 비밀번호, 존재하지 않는 id, 같은 이름의 다른 방명록 글은 각자의 비밀번호로만 삭제됨
