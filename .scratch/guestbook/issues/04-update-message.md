# 04: 비밀번호로 메시지 수정

**What to build:** 글쓴이가 방명록 글의 "수정"을 누르면 기존 메시지가 채워진 입력칸과 비밀번호 입력칸이 그 자리에 펼쳐지고, 올바른 비밀번호로 메시지를 고칠 수 있다. 이름·작성 시각·목록 순서는 바뀌지 않으며, 수정된 방명록 글에는 "(수정됨 · 수정 시각)"이 표시된다. 비밀번호 불일치와 이미 삭제된 경우는 03과 같은 방식으로 안내한다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 03 (비밀번호로 방명록 글 삭제) — 03의 인라인 입력칸 구조를 재사용

**Status:** ready-for-agent

- [ ] guestbook 모듈의 메시지 수정 연산이 `ok` | `invalid` | `wrong-password` | `not-found`를 반환한다
- [ ] 성공 시 메시지와 수정 시각만 바뀌고 이름·작성 시각·목록 순서는 그대로다
- [ ] 수정 메시지도 1–500자 검증과 앞뒤 공백 제거를 받는다
- [ ] "수정"을 누르면 기존 메시지가 채워진 입력칸 + 비밀번호 입력칸이 펼쳐진다 (한 번에 하나만 열림, 취소 가능)
- [ ] 틀린 비밀번호 → 빨간 "비밀번호가 일치하지 않습니다", 입력하던 새 메시지 유지
- [ ] 이미 삭제된 방명록 글 → "이미 삭제된 글입니다" 안내 후 목록 새로 고침
- [ ] 수정된 방명록 글에 "(수정됨 · 수정 시각)"이 작게 표시된다
- [ ] 테스트: 올바른/틀린 비밀번호, 검증 실패, 존재하지 않는 id, 수정 후 이름·작성 시각·순서 불변과 수정 시각 설정
