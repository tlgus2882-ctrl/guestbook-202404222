# 02: 방명록 글 작성

**What to build:** 방문자가 이름·메시지·비밀번호를 입력해 방명록 글을 남기면 목록 맨 위에 바로 나타난다. 잘못된 입력은 필드별 안내와 함께 거부되고, 입력하던 값은 유지된다. 비밀번호는 해시로만 저장된다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 01 (방명록 목록 보기)

**Status:** ready-for-agent

- [ ] 구현 전에 Next.js 16.3 문서에서 Server Actions·폼·재검증 가이드를 확인했다
- [ ] guestbook 모듈의 작성 연산이 `ok`(생성된 방명록 글) 또는 `invalid`(필드별 오류)를 반환한다
- [ ] 앞뒤 공백을 자른 뒤 이름 1–20자, 메시지 1–500자, 비밀번호 4–50자를 검증한다 (공백만 입력 시 거부)
- [ ] 비밀번호는 `crypto.scrypt` + 무작위 salt로 해시되어 저장되며 평문은 어디에도 남지 않는다
- [ ] 작성 폼(이름, 메시지 textarea, 비밀번호 password 입력)이 Server Action으로 연결된다
- [ ] 검증 실패 시 필드별 오류가 표시되고 입력값이 유지된다
- [ ] 제출 중 버튼이 비활성화된다
- [ ] 성공 시 새 방명록 글이 목록 맨 위에 나타나고 폼이 비워진다
- [ ] 같은 이름으로 여러 방명록 글을 남길 수 있다
- [ ] 테스트: 작성 후 목록에 최신순으로 나타남, 경계 길이(20/21, 500/501, 3/4/50/51), 빈 값·공백만, 앞뒤 공백 제거
